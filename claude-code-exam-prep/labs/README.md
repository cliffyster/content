# Labs

Five exercises. Each one makes you build the thing rather than read about it,
because the exam tests details you only notice when your version doesn't work.

| Lab | Build | Note to read first |
|---|---|---|
| [01](lab-01-hooks/) | A `PreToolUse` hook that blocks a class of command | [04 — Hooks](../notes/04-hooks.md) |
| [02](lab-02-skill/) | A skill with arguments and a scoped tool grant | [03 — Skills](../notes/03-skills-and-commands.md) |
| [03](lab-03-subagent/) | A subagent that *cannot* write, by construction | [05 — Subagents](../notes/05-subagents.md) |
| [04](lab-04-mcp-server/) | A stdio MCP server, wired into Claude Code | [06 — MCP](../notes/06-mcp.md) |
| [05](lab-05-agent-sdk/) | An agent loop with the SDK Tool Runner | [07 — Agents and SDKs](../notes/07-agents-and-sdks.md) |

Each lab has a `solution/`. Open it after you have something of your own that
runs — a solution you read before trying teaches nothing.
